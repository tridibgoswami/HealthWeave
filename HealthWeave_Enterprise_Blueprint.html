🏥

👤

Consumers managing their own health. Expect Gmail/Dropbox UX. Want free tier, mobile-first, family health, report uploads, doctor sharing, and emergency QR code access.

Part Three

Multi-Tenancy Architecture

Pooled multi-tenancy with isolated tiers — the gold standard for healthcare SaaS that balances cost efficiency with enterprise data isolation demands.

3.1 Three-Tier Tenancy Strategy

🏊
Tier 1 — Shared Pool

B2C patients + SMB clinics. Shared database, application servers, infrastructure. Row-level security via organization_id. Cost-efficient. Covers 95% of clients.

🗄️
Tier 2 — Dedicated Database

Hospital chains with 1K–10K patients. Own isolated PostgreSQL DB, shared app servers. Data never touches another tenant's database. Custom workflows per tenant.

🏛️
Tier 3 — Fully Isolated

Government hospitals, highly regulated enterprises. Separate K8s namespace, separate DB, separate AI pipeline. Physical data isolation. ₹50L+ annual contracts.

Part Four

Security Architecture

A single breach ends the company. Security in healthcare is a product feature, a sales lever, and a legal obligation simultaneously.

4.1 Seven-Layer Security Model

1
Network Security

Cloudflare Enterprise WAF (OWASP Top 10 blocking) · DDoS protection at network edge · Private VPC — API servers and databases never on public internet · Port 5432 accessible only from API server's private subnet

2
Identity & Authentication

JWT (15-min access / 7-day refresh with rotation) · MFA mandatory for all clinical staff and admins · FIDO2/WebAuthn for super-admins · SSO via SAML 2.0 / OIDC for enterprise (Azure AD, Okta, Google Workspace) · Geographic anomaly detection

3
Authorization & Access Control

RBAC with fine-grained permissions · ABAC for sensitive records (HIV status visible only to specific specializations with explicit consent) · Consent management per record category · Break-glass access for critical care with full audit trail

4
Data Encryption

TLS 1.3 everywhere in transit · AES-256 at rest · Field-level encryption for HIV/mental health/reproductive data (per-patient KMS key) · Pre-signed time-limited URLs for documents · 90-day automatic key rotation · Envelope encryption

5
Application Security

Pydantic validation on every endpoint · ORM-only SQL (no raw string queries in production) · CORS whitelist · Rate limiting per-IP/per-user/per-org · ClamAV virus scanning on uploads · AI prompt injection prevention · Dependabot + Snyk dependency scanning

6
Audit & Compliance

Immutable write-once audit log for every data access/modification/deletion · Separate append-only storage (S3 Object Lock) · Patient-downloadable access reports · DPDP 2023: right to access, correction, erasure, consent · ISO 27001 target Year 2 · SOC 2 Type II target Year 2

7
Infrastructure Security

HashiCorp Vault / AWS KMS for secrets (no secrets in code or env files) · Trivy/Snyk container scanning before every deploy · Quarterly external pen test · Zero-trust mTLS for all internal service-to-service communication · Immutable infrastructure — no SSH to production, all changes via CI/CD · Terraform IaC

The Non-Negotiables

Four Architecture Decisions That Cannot Be Undone

These are not preferences. They are foundational bets that shape every other decision for the next five years.

01

SaaS First. On-Premise Never (in Year 1)

Do not let any enterprise client convince you to build on-premise software in Year 1. It will bifurcate the codebase, triple support burden, and kill the ability to ship product improvements. The answer to "can we host it ourselves?" is: "We offer a dedicated, fully isolated cloud environment that meets your data residency requirements — it is more secure than your own data center because our team monitors it 24/7 and applies security patches within hours."

02

Multi-Tenancy Right from Day One — No Exceptions

Row-level security with organization_id on every table, every query scoped, every API response filtered. An audit finding a data leak between tenants ends the business immediately in healthcare. There is no recovery from a healthcare data breach in India.

03

The AI Data Strategy Is the Moat

Every record processed, every biomarker extracted, every interaction pattern — with appropriate anonymization and explicit consent — builds understanding no competitor has. At 1 million records, HealthWeave understands Indian diet patterns, Indian lab reference ranges, Indian medication brands, and Indian disease prevalence better than any American or European model. This is defensible, compounding, and irreplaceable. Guard and grow this asset. It is worth more than the code.

04

Compliance Is a Product Feature, Not a Tax

Hospitals and enterprise clients do not buy software. They buy trust. The ISO 27001 certificate, DPDP compliance, and ABDM certification are not checkboxes — they are sales collateral and moat. Start compliance work in Year 1 even when it feels premature. Certification takes 12–18 months. You want the certificate ready when the first ₹1 crore annual contract is on the table.
